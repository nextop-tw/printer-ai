## 操作流程

### 處理訂單流程

```
訂單列表（篩選「已付款」）
  → 點擊訂單 → 訂單詳情
    → 確認圖檔（下載查看）
    → 選擇接單中的印刷廠 → 點擊「指派」
    → 系統自動發 LINE → 狀態變「已指派」
  → 日後進入更新狀態（生產中→出貨→完成）
```

### 新增印刷廠流程

```
印刷廠列表 → [+ 新增印刷廠] → 填寫表單
  → 儲存 → 返回列表
```
