# 印刷媒合平台 User Stories

**版本：** v1.1
**最後更新：** 2026-05-04

---

## US-001 上傳設計稿並即時分析

**User Story：**
身為用戶，
我想要上傳設計稿後立即知道檔案是否符合印刷規格，
以便在下單前發現問題。

**驗收條件：**
- Given 用戶上傳 JPG/PNG/PDF，When 上傳完成，Then 10 秒內顯示分析結果（解析度、色彩模式、出血）
- Given 解析度不足，When 系統偵測到，Then 顯示警告訊息並建議重新上傳
- Given 上傳格式不符，When 用戶選擇不支援的格式，Then 顯示錯誤並拒絕上傳

---

## US-002 選規格即時報價

**User Story：**
身為用戶，
我想要選擇印刷規格後立即看到價格，
以便決定是否下單。

**驗收條件：**
- Given 用戶選擇產品類型，When 頁面載入，Then 顯示該產品對應的規格維度選項
- Given 用戶變更任一規格，When 選項改變，Then 價格即時更新
- Given 數量達折扣門檻，When 達到，Then 自動套用折扣並顯示折扣後價格

---

## US-003 下單與付款

**User Story：**
身為用戶，
我想要確認訂單並完成線上付款，
以便啟動印刷流程。

**驗收條件：**
- Given 用戶確認規格與圖檔，When 點擊下單，Then 導向藍新金流付款頁
- Given 付款成功，When 金流回調，Then 建立訂單、建立帳號、發送 email 通知
- Given 付款失敗，When 金流回調，Then 顯示失敗訊息並允許重試

---

## US-004 自動建立帳號

**User Story：**
身為首次下單的用戶，
我想要付款後自動擁有帳號，
以便日後查看歷史訂單而不需重新填寫資料。

**驗收條件：**
- Given 付款成功且 email 為新帳號，When 系統建立帳號，Then 發送設定密碼 email
- Given 用戶點擊 email 連結，When 設定密碼完成，Then 可登入查看訂單

---

## US-005 訂單狀態追蹤

**User Story：**
身為用戶，
我想要查看訂單目前的進度與預計完成日，
以便掌握印刷品到手的時間。

**驗收條件：**
- Given 用戶登入，When 進入訂單列表，Then 顯示所有歷史訂單與狀態
- Given 訂單被指派給印刷廠，When 管理員確認，Then 顯示預計完成日

---

## US-006 管理員維護規格與定價

**User Story：**
身為管理員，
我想要靈活管理規格維度、選項與定價，
以便新增產品類型時不需修改程式。

**驗收條件：**
- Given 管理員新增規格維度，When 儲存，Then 可在產品類型中勾選使用
- Given 管理員設定組合基本價，When 用戶選擇該組合，Then 前台正確帶出價格
- Given 管理員設定數量折扣，When 儲存，Then 達門檻時自動套用

---

## US-007 管理員審核訂單並指派印刷廠

**User Story：**
身為管理員，
我想要審核訂單並指派給適合的印刷廠，
以便啟動生產並通知廠商。

**驗收條件：**
- Given 有新訂單，When 管理員進入後台，Then 顯示待審核訂單列表
- Given 管理員選擇印刷廠，When 點擊指派，Then 僅顯示接單中的廠商
- Given 指派成功，When 確認，Then 系統透過 LINE Messaging API 通知印刷廠，訂單狀態更新為「生產中」

---

## US-008 管理員強制控制印刷廠接單狀態

**User Story：**
身為管理員，
我想要強制暫停或恢復某間印刷廠的接單，
以便在廠商無法自行處理時緊急介入。

**驗收條件：**
- Given 管理員強制暫停某廠，When 儲存，Then 該廠不出現在指派選單中
- Given 管理員強制恢復，When 儲存，Then 該廠重新出現在指派選單

---

## US-009 印刷廠管理自身接單狀態

**User Story：**
身為印刷廠，
我想要自行設定接單狀態與工作天數，
以便在產能滿載時暫停接單。

**驗收條件：**
- Given 印刷廠登入，When 切換為「暫停接單」，Then 管理員指派頁不顯示該廠
- Given 印刷廠更新工作天數，When 儲存，Then 新訂單指派後預計完成日依新天數計算
