**最後更新：** 2026-05-04

## 模組說明

### 前台（用戶端）
| 模組 | 說明 |
|------|------|
| 圖檔上傳分析 | 上傳後用 Imagick 即時檢查解析度（300 DPI）、色彩模式（RGB/CMYK）、出血區域 |
| 規格選擇與報價 | 依產品類型動態載入規格維度，即時計算疊加價格與數量折扣 |
| 下單付款 | 藍新金流整合，付款成功後建立訂單與用戶帳號 |
| 帳號管理 | 首次下單自動建立帳號，發 email 設定密碼 |
| 訂單追蹤 | 登入後查看歷史訂單、狀態、預計完成日 |

### 後台（管理員）
| 模組 | 說明 |
|------|------|
| 規格系統管理 | 規格維度（Table A）、規格選項（Table B）、產品類型管理 |
| 定價管理 | 主規格組合基本價、加工疊加加價、數量折扣區間 |
| 印刷廠管理 | 廠商資料、工作天數、強制暫停控制 |
| 訂單管理 | 列表、審核、指派印刷廠、狀態更新 |
| LINE 通知 | 指派後自動透過 LINE Messaging API 通知印刷廠 |

### 印刷廠端
| 模組 | 說明 |
|------|------|
| 訂單查看 | 查看被指派的訂單與圖檔 |
| 接單狀態 | 自行切換接單中 / 暫停接單 |
| 工作天數 | 自行更新，影響預計完成日計算 |

## API 結構

### 前台 API

| Method | URI | 說明 |
|--------|-----|------|
| GET | `/api/product-types` | 取得所有產品類型 |
| GET | `/api/product-types/{id}/specs` | 取得產品的規格維度與選項 |
| POST | `/api/quote` | 計算即時報價（含數量折扣） |
| POST | `/api/upload` | 上傳圖檔並回傳分析結果 |
| POST | `/api/orders` | 建立訂單（付款前） |
| POST | `/api/payment/callback` | 藍新金流付款回調 |
| GET | `/api/orders/{orderNo}` | 查詢訂單狀態 |

### 後台 API（需管理員登入）

| Method | URI | 說明 |
|--------|-----|------|
| GET | `/admin/orders` | 訂單列表 |
| PATCH | `/admin/orders/{id}/assign` | 指派印刷廠 |
| PATCH | `/admin/orders/{id}/status` | 更新訂單狀態 |
| CRUD | `/admin/spec-dimensions` | 規格維度管理 |
| CRUD | `/admin/spec-options` | 規格選項管理 |
| CRUD | `/admin/product-types` | 產品類型管理 |
| CRUD | `/admin/base-prices` | 基本價管理 |
| CRUD | `/admin/quantity-discounts` | 數量折扣管理 |

## 定價計算邏輯

```
總價 = (基本價 + Σ加工加價) × 數量折扣率
```

1. 依用戶選擇的主規格組合（尺寸 × 紙張 × 材質）查 `product_base_prices` 取得基本價
2. 依用戶勾選的加工選項查 `spec_options.price_addon` 加總
3. 依數量查 `quantity_discounts` 取得對應折扣率
4. 計算後的總價存入訂單快照，不再動態計算

## 資料流

### 用戶下單流程

```
上傳圖檔 → Imagick 分析 → 回傳警告（若有）
    ↓
選規格 → 即時計算報價
    ↓
確認下單 → 建立 pending 訂單
    ↓
導向藍新金流
    ↓
付款成功回調 → 建立 user → 發 email → 訂單狀態改 paid
```

### 管理員指派流程

```
後台看到 paid 訂單 → 審核圖檔
    ↓
選擇接單中的印刷廠 → 指派
    ↓
計算預計完成日（今日 + 工作天數）
    ↓
LINE Messaging API 通知印刷廠
    ↓
訂單狀態改 assigned
```

## 技術選型說明

| 技術 | 選用理由 |
|------|---------|
| Laravel | 成熟的 PHP 框架，內建 Queue、Mail、Auth，適合此規模 |
| MySQL | 關聯式資料，規格組合查詢需要 JOIN，關聯式 DB 較合適 |
| Imagick | PHP 原生擴充，無需外部服務即可分析圖檔 |
| 藍新金流 | 台灣本地金流，整合文件完整 |
| LINE Messaging API | 印刷廠已有 LINE，無需額外安裝 App |
