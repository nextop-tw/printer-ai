常見問題

你可能想問的問題

不訂閱方案也能使用嗎？

可以。免費方案每月提供 5 次免費檔案分析，也可以在不訂閱的情況下按量付費下單印刷。

支援哪些檔案格式？

支援 JPG、PNG、PDF，最大 20MB。建議使用 PDF/X-3 格式以獲得最佳印刷品質。

自動修正引擎是怎麼運作的？

引擎採用業界標準色彩設定檔進行 RGB 轉 CMYK、AI 演算法提升解析度，並以程式化方式延伸邊緣補出血。你可以選擇要套用的修正項目，再下載修正後的檔案。

印刷訂單可以退款嗎？

若收到的印刷品有瑕疵或與核准預覽不符，我們將免費重印或退款。通過偵測系統但在製作開始後取消的訂單，恕無法退款。

可以將 PrinterAI 整合到自己的平台嗎？

可以。企業版包含 REST API 存取、Webhook 支援與白牌偵測元件。如需每月超過 1 萬次 API 呼叫的自訂方案，請聯絡業務團隊。
